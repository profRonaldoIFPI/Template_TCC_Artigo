# Diretório de Especificações (`spec/`)

Este diretório contém os arquivos de especificação do projeto do template de TCC em formato de artigo científico. Ele detalha os requisitos estruturais e regras de conformidade técnica mapeadas para o desenvolvimento e manutenção do próprio template.

## Conteúdo do Diretório

- **`specification.md`**: Documento contendo as especificações técnicas, mapeamento de comandos LaTeX, validação de regras de margens, estilos de citações e compatibilidade com normas.
- **`estrutura-tcc.md`**: Detalhamento da tabela comparativa e estrutura lógica do artigo acadêmico exigido para o IFPI Campus Floriano.

---

## O que se pode ou deve alterar?

> [!IMPORTANT]
> Este diretório serve para fins de **desenvolvimento, especificação técnica e documentação estrutural** do repositório. O conteúdo aqui contido não interfere na compilação do seu documento LaTeX ou no resultado final do PDF do seu TCC.

### 🟢 O que pode ser alterado/adicionado:
- **Novas especificações**: Se novas regras de validação ou scripts de automação forem desenvolvidos para o template, as instruções de especificação podem ser descritas neste diretório.
- **Instruções de Manutenção**: Se houver necessidade de documentar detalhes internos do comportamento de estilos e macros LaTeX para futuros desenvolvedores ou mantenedores do template.

### 🔴 O que NÃO deve ser alterado:
- Não delete os arquivos existentes, pois servem como registro e garantia de qualidade (QA) para atestar que o template segue rigorosamente as diretrizes oficiais do manual de TCC do IFPI e da ABNT.
